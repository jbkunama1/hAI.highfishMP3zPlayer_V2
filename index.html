Features

⚡
60k Tracks
In-Memory-Index + Paginierung (80/Seite). Suche in unter 50ms nach Index-Build.
🎵
Streaming
HTTP Range-Requests → Seek ohne Buffering. Formate: MP3, FLAC, M4A, OGG, WAV, AAC, OPUS, WMA.
🔍
Globale Suche
Serverseitige Volltextsuche über alle 60k Dateien. Ab 3 Zeichen automatisch global.
🔀
Shuffle & Repeat
Fisher-Yates Shuffle der Queue. Repeat: Aus / Einen / Alle. Tastenkürzel S und R.
🔐
Passwortschutz
Login-Screen mit Samba-Credentials als API-Key. Timing-Attack-sicher via secrets.compare_digest + SHA-256-Hash.
🖼
Album-Cover
ID3-Tags (MP3/FLAC/M4A) oder cover.jpg. 24h Browser-Cache.
📱
PWA + APK
Service Worker, manifest.json, Lockscreen-Controls. PWABuilder → echte Android APK in Minuten.
📋
Queue
Einzelne Tracks oder ganzen Ordner (paginiert). Queue mischen, leeren, verwalten.
🌐
CORS + Cloudflare
Zugriff via Cloudflare / eigener Domain. Kostenlos HTTPS durch Cloudflare-Proxy.
🏠
100% Self-hosted
Eine Python-Datei. DietPi/Debian mit systemd-Autostart oder Docker/Portainer-Stack (GHCR, Port 8066, highfishNetwork).

Installation

Python 3.9+
DietPi / Debian 11
flask · flask-cors · mutagen · python-dotenv · pillow
Port 80 / Docker 8066 · highfishNetwork
1
Repo klonen
Ins Zielverzeichnis klonen.
mkdir -p /opt/mp3z && cd /opt/mp3z
git clone https://github.com/jbkunama1/hAI.highfishMP3zPlayer_V2.git .
2
Dependencies
Alle Abhängigkeiten auf einmal.
pip install -r requirements.txt --break-system-packages
3
.env konfigurieren
Zugangsdaten setzen — wird nicht committet.
cp .env.example .env && joe .env
# Anpassen:
MUSIC_ROOT=/mnt/USBHDD_MP3z
SMB_USER=daniel
SMB_PASS=deinSambaPasswort
API_KEY_OVERRIDE=  # optional: eigener API-Key
4
Icons generieren
Einmalig ausführen.
python3 generate_icons.py
✓ icon-192.png
✓ icon-512.png
5
Starten
python3 mp3z_server.py
🎵 hAI.highfishMP3zPlayer  v2.0.0
✓ Index: 61243 Dateien in 18.3s
6
Autostart systemd
cp systemd/mp3z.service /etc/systemd/system/
systemctl enable mp3z && systemctl start mp3z
7
APK via PWABuilder
https://pwabuilder.com
# URL eingeben → Android → Download Package
8
Docker / Portainer (optional)
Statt systemd: Stack direkt aus dem Repo deployen — das Image baut GitHub Actions automatisch und pusht es zu GHCR.
Portainer → Stacks → Add stack → Repository
# Repo:  jbkunama1/hAI.highfishMP3zPlayer_V2
# Pfad:  docker-compose.yml   (Referenz: main / vX.Y.Z)
# Env:   SMB_USER · SMB_PASS · API_KEY_OVERRIDE · DEFAULT_URL
# Netz:  highfishNetwork (vorher extern anlegen!)
# Extern erreichbar auf Port 8066
docker pull ghcr.io/jbkunama1/hai.highfishmp3zplayer_v2:latest
docker run -d --name mp3z -p 8066:80 --network highfishNetwork \
  -v /mnt/USBHDD_MP3z:/music:ro \
  -e SMB_USER=daniel -e SMB_PASS=deinSambaPasswort \
  -e API_KEY_OVERRIDE=deinEigenerAPIKey \
  ghcr.io/jbkunama1/hai.highfishmp3zplayer_v2:latest
Entwickler-Docs

REST API

POST /api/verify
Login — prüft API-Key, gibt User zurück (kein Auth)
{"apikey": "deinPasswort"}
GET /api/client-config
Öffentliche App-Konfiguration (kein Auth)
→ DEFAULT_URL, Titel, Version
GET /api/browse
Paginiertes Verzeichnis-Listing
?path=Artist/Album&offset=0&limit=80
GET /api/search
Globale Volltextsuche über alle 60k Tracks
?q=dire+straits&offset=0&limit=100
GET /api/stream
Audio-Streaming mit Range-Support (Seek ohne Buffering)
?path=Artist/song.mp3&apikey=...
Header: Range: bytes=0-
GET /api/art
Album-Cover aus ID3-Tags oder cover.jpg
?path=Artist/Album&apikey=...
Cache-Control: 86400
GET /api/index-status
Index-Statistik
→ Anzahl Dateien, Build-Zeit
Auth
Alle Endpoints außer verify/client-config brauchen den API-Key.
Header:    X-API-Key: deinPasswort
URL-Param: ?apikey=... (stream/art)
